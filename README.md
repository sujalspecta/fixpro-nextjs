# Fixpro — Electronics & Gadgets Repair Services Next.js Template

Fixpro is a modern, unique, and fully responsive Next.js template designed specifically for electronics and gadget repair businesses. It is an ideal solution for service providers offering repairs for AC units, mobile phones, computers, laptops, and other electronic devices.

Fixpro is fully responsive and optimized for all devices and screen sizes, including laptops, tablets, iPads, iPhones, and Android devices. The flexible and easy-to-understand code structure ensures that developers of any level can quickly update and modify the template according to their needs.

## Getting Started

### Prerequisites

Make sure **Node.js** is installed on your computer.

```bash
node -v
```

This will display the installed Node version. If it's not installed, refer to the [Next.js Installation Docs](https://nextjs.org/docs/app/getting-started/installation).

---

### Installation & Setup

**1. Navigate to the project folder:**

```bash
cd fixpro
```

**2. Install dependencies:**

```bash
npm install
```

This will create a `node_modules` folder where all dependency files will be installed.

**3. Run the development server:**

```bash
npm run dev
```

The project will be compiled and loaded at [http://localhost:3000](http://localhost:3000).

**4. Production build:**

```bash
npm run build
```

Bundles Next.js in production mode and optimizes the build for the best performance.

> Learn more in the [Next.js Documentation](https://nextjs.org/docs).
